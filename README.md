# Tempo de Salón

App web instalable (PWA) para ensayar bailes de salón con tus vídeos: BPM de ensayo sin cambiar el
tono, tramo y bucle por vídeo, separación de instrumentos en el propio dispositivo y partitura de los
canales elegidos que avanza con el vídeo.

**App:** https://xjav-dev.github.io/tempo/ (lleva a `publicar/`)

La documentación está en castellano: empieza por [LEEME.md](LEEME.md). GitHub Pages publica la rama `main`: la portada `index.html` lleva a la app, que está en `publicar/`.
Cada cambio que se sube a `main` se publica solo.
